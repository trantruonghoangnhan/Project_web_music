# MusicAyGiBiTeo (MAGBT)

Chào mừng bạn đến với **MusicAyGiBiTeo (MAGBT)**, một dự án website nghe nhạc trực tuyến với giao diện hiện đại, thân thiện và đẹp mắt.

## 🎵 Giới thiệu

**MusicAyGiBiTeo** là một trang web nghe nhạc được xây dựng bằng HTML, CSS, và JavaScript thuần. Dự án mang đến trải nghiệm nghe nhạc mượt mà với nhiều tính năng hấp dẫn, giao diện được thiết kế mang phong cách hiện đại và có khả năng tương thích tốt với nhiều loại thiết bị (responsive).

## 🚀 Các tính năng nổi bật

- **Khám Phá:** Cập nhật những bài hát, album và nghệ sĩ thịnh hành nhất.
- **Trình Phát Nhạc Cực Chất:** Giao diện player bar trực quan, hỗ trợ đầy đủ các chức năng play/pause, next/prev, lặp lại (repeat), phát ngẫu nhiên (shuffle), và điều chỉnh âm lượng.
- **Danh Sách Phát Đa Dạng:** Tích hợp sẵn nhiều bài hát từ các nghệ sĩ nổi tiếng.
- **Tìm Kiếm & Thư Viện:** Dễ dàng tìm kiếm và lưu trữ các bài hát yêu thích.
- **Lab Thực Hành:** Tích hợp các bài tập và thực hành (dành riêng cho mục đích học tập).
- **Giao Diện Responsive:** Hiển thị tốt trên cả máy tính, máy tính bảng và điện thoại di động.

## 🛠 Công nghệ sử dụng

- **HTML5 & CSS3:** Xây dựng cấu trúc và định dạng giao diện.
- **JavaScript (Vanilla):** Xử lý logic phát nhạc, carousel banner và các tương tác người dùng.
- **FontAwesome:** Sử dụng các icon vector đẹp mắt.

## 📌 Cách chạy dự án

1. Clone hoặc tải mã nguồn về máy.
2. Mở file `index.html` trực tiếp trên trình duyệt của bạn (Chrome, Edge, Firefox, Safari,...).
3. Hoặc có thể sử dụng các extension như **Live Server** trên VS Code để có trải nghiệm tốt nhất.
